## Catalogues
- translations/messages.fr.php + messages.en.php : **360 clés** chacune
  (278 du lot 2a + 82 nouvelles du lot 3), symétriques, sans doublon.
- Remplacez vos fichiers du lot 2a par ceux-ci (fusion déjà faite).
- Nouvelles familles : event.sidebar.*, event.show.*, event.status.past_event,
  blog.* (list, sidebar, share, category, show, read_suffix), presentation.*,
  profile.*, badge.visitor, newsletter.*.
- Quelques messages contiennent du HTML (lien "rejoins l'assoc'", <strong>%email%</strong>)
  rendus avec |raw dans les templates.

## Test
- tests/Controller/Front/ContentTranslationTest.php (2 tests) :
  sidebar événements + hero Présentation, en FR par défaut puis EN après /locale/en.
  Aucune fixture requise (assertions sur textes toujours rendus).

## Déploiement (rituel habituel)
1. Extraire ce zip à la racine du projet (il écrase les 12 templates, les 2 catalogues, ajoute le test).
2. php bin/phpunit
3. git add/commit/push
4. Serveur (CT 202) :
   pct exec 202 -- bash -c 'cd /var/www/geomonkey && git pull && php bin/console cache:clear --env=prod && systemctl reload php8.4-fpm'
5. Vérifier sur geomonkey.fr : /evenements (sidebar), /presentation, /blog (catégorie),
    et une fiche événement/article pour les badges et boutons i18n.
