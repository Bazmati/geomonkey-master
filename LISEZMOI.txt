i18n Lot 2a — Formulaires front (connexion, inscription, don)
==============================================================

PÉRIMÈTRE :
- 12 templates convertis : security/{login,forgot_password,reset_password},
  membership/{register,payment_required,success,check_email,wait_validation,cancel},
  donation/{index,success,cancel}
- Textes statiques + placeholders des inputs (les placeholders inline sont
  traduits via clés ; les 3 templates à formulaire ont aussi leurs pitchs
  "pourquoi rejoindre/donner" traduits)
- Catalogues : 153 -> 278 clés symétriques (125 nouvelles : auth.*, register.*, donation.*,
  + réut. form.email, legal.back_home)

FRONTIÈRE (à connaître) :
- Les LIBELLÉS des champs Symfony (form_label) viennent des FormType
  (RegistrationType, DonationType...) : ils restent en FR pour l'instant.
- Les messages de VALIDATION Symfony (contraintes) restent en FR.
- Le CONTENU des flashs (addFlash dans les contrôleurs) reste en FR.
  -> traités dans un Lot 2b ultérieur (FormType + flashs + validators).
- Le message d'erreur de connexion est auto-adapté : error.messageKey|trans(...,'security')
  suit la locale (domaine security de Symfony).

Détail technique : les clés contenant du HTML (register.price_label,
register.pay.secure, register.check.warn, register.wait.important,
register.cancel.no_fee, auth.already_logged) sont rendues avec |raw
(car Twig auto-escape la sortie de trans).
