==========================================================

CONTENU (a extraire a la racine du projet) :
- config/packages/translation.yaml     (NOUVEAU : translator active,
  default_locale fr, fallback fr)
- src/EventSubscriber/LocaleSubscriber.php (NOUVEAU : relit la locale

COMportement :
- Defaut : francais (sans session ni cookie).
- Bouton FR/EN dans la navbar (icone bi-translate + code locale).
- La langue survit a la session via cookie gm_locale (1 an, secure,
  httpOnly, samesite lax). Referer du meme hote seulement (anti
  open-redirect).
- URLs STRICTEMENT identiques dans les deux langues : SEO FR preserve.
- Le contenu de la base (articles, evenements...) reste en francais :
  l'i18n ne traduit que l'interface.

IMPORTANT :
- Pas de composer install necessaire (symfony/translation 8.0 deja
  present dans composer.json).
- ATTENTION : la navbar fournie remplace la tienne (elle est la
  version a jour du repo + i18n). Verifie git diff avant d'ecraser.
- Lot 0 volontairement limite : les PAGES (home, legal, evenements...)
  sont encore en francais natural dans leurs templates. Lots suivants :
  pages publiques, formulaires/flashs/validation, backoffice plus tard.
