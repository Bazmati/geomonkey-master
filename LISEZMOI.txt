# i18n Lot 2c : fil d'Ariane bilingue + derniers fragments (front)

## Périmètre
- src/Twig/BreadcrumbExtension.php
  TranslatorInterface injecté (3e argument du constructeur).
  Les libellés des routes FRONT sont traduits via les clés nav.* du catalogue
  (nav.home, nav.blog, nav.events, nav.gallery, nav.presentation, nav.join).
  Les libellés du backoffice restent FR (hors périmètre tant que pas multi-assos).
  Les libellés d'entités (titre d'un événement, nom d'un tag...) viennent de la
  base et ne sont pas traduits (contenu DB, frontière i18n connue).
- templates/front/tag.html.twig
  Le fragment fil d'Ariane des pages tag utilise maintenant
  'nav.home'|trans et 'nav.blog'|trans au lieu de « Accueil » / « Actualités ».
- src/Controller/Front/MembershipController.php
  Le flash « Aucun tarif d'adhésion défini en base de données » (quand aucun
  MembershipFee n'existe) passe par la clé flash.register.no_fee au lieu de
  $e->getMessage(). Le texte FR est IDENTIQUE à l'original (les tests
  existants_ASSERT_FR passent inchangés).

## Catalogues
- translations/messages.fr.php + messages.en.php : **421 clés** chacune
  (420 du lot 2b + 1 nouvelle : flash.register.no_fee).

## Test
- tests/Controller/Front/BreadcrumbTranslationTest.php (2 tests) :
  fil d'Ariane de /presentation et /evenements en FR par défaut puis EN.

## Piège connu
BreadcrumbExtension a maintenant 3 arguments de constructeur
(RequestStack, UrlGeneratorInterface, TranslatorInterface). Si un test
l'instancie directement, il doit passer le translator (mock TranslatorInterface).

## Déploiement (rituel habituel)
1. Extraire à la racine du projet (5 fichiers écrasés + 1 nouveau test).
2. php bin/phpunit
3. git add/commit/push
4. CT 202 : git pull + cache:clear --env=prod + reload php8.4-fpm
5. Vérifier en EN : /evenements (Accueil > Événements devient Home > Events),
   /presentation (About), une catégorie ou un tag de blog (fil du fragment tag),
   et /inscription sans tarif en base (flash traduit — non testable en prod
   puisqu'un tarif existe).
