# i18n Lot 2b : libellés FormType, validation et flashs contrôleurs (front)

## Périmètre

### FormTypes (labels + messages de validation traduits via TranslatorInterface)
- src/Form/DonationType.php
- src/Form/ProfileType.php
- src/Form/RegistrationFormType.php

Principe : les FormTypes sont des services Symfony (autoconfigure/autowire),
le TranslatorInterface est injecté en constructeur et les libellés/messages
sont traduits à la construction du formulaire (domaine `messages`).
Les placeholders de validation ({{ limit }}, {{ min }}, {{ max }}) sont
conservés par trans() puis remplacés par le validator.

### Contrôleurs front (flashs + messages 404 traduits)
- src/Controller/Front/DonationController.php   (erreur paiement Stripe)
- src/Controller/Front/MembershipController.php (emails, vérification email, mot de passe oublié/réinitialisé)
- src/Controller/Front/ProfileController.php    (profil mis à jour)
- src/Controller/Front/EventController.php      (inscription/désinscription événement, CSRF, 404)
- src/Controller/Front/NewsletterController.php (inscription newsletter)

Frontières volontairement laissées FR :
- MembershipFeeService->getCurrentAmountInEuros() : le message d'erreur du service
  (flash sur /inscription quand aucun tarif n'existe) reste FR.
- MembershipFeeType : formulaire back-office, hors périmètre.
- Emails transactionnels (déjà traités à part, non concernés ici).

## Déploiement (rituel habituel)
1. Extraire ce zip à la racine du projet. Il écrase :
   3 FormTypes, 5 contrôleurs, les 2 catalogues, 2 fichiers de test.
2. `php bin/phpunit tests/Controller/Front/`
   (si un FormType n'est pas reconnu comme service, vérifier que
   services.yaml autoconfigure bien App\\ — c'est la config standard du repo)
3. git add/commit/push
4. Serveur (CT 202) :
   pct exec 202 -- bash -c 'cd /var/www/geomonkey && git pull && php bin/console cache:clear --env=prod && systemctl reload php8.4-fpm'
5. Vérifier sur geomonkey.fr en EN : /don (libellés + soumission vide),
   /inscription (labels, radios, CGA cliquables), inscription/désinscription
   à un événement (flash), inscription newsletter depuis l'accueil (flash).
