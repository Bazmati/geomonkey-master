# Feature : dons — net après frais Stripe (comptabilité asso)

## Contenu

Ce dossier contient 7 fichiers MODIFIÉS + ce README. Les chemins reproduisent
l'arborescence du projet : extraire à la racine du repo (là où se trouvent
`src/` et `templates/`), les fichiers écrasent les existants.

Fichiers modifiés :

1.  src/Entity/Donation.php
    -> nouvelles colonnes fee_amount et net_amount (nullable, centimes) + getters/setters + getNetInEuros()
2.  src/Repository/DonationRepository.php
    -> getNetTotalForYear() et getNetTotal() (totaux nets pour la trésorerie)
3.  src/Service/StripeService.php
    -> getDonationFees() : lit le balance_transaction officiel de Stripe,
       ne jette jamais (retourne null si indisponible)
4.  src/Controller/Webhook/StripeWebhookController.php
    -> handleDonationSessionCompleted() remplit fee/net au passage en "paid"
5.  src/Controller/Admin/DonationController.php
    -> passe totalNetThisYear / totalNetAllTime au template
6.  templates/admin/donation/index.html.twig
    -> totaux "Net après frais Stripe" sur les 2 cartes + colonne net dans le tableau
7.  src/Controller/Admin/ExportController.php
    -> export CSV dons : colonnes "Frais Stripe (€)" et "Net (€)" ajoutées

Bonus inclus dans ce lot (sans rapport direct avec le net) :

8.  src/Service/CsvExporter.php
    -> déprecations PHP 8.4 corrigées : fputcsv() avec $escape explicite ('')

## Installation en local

Depuis la racine du repo, après avoir extrait les fichiers :

    php bin/console make:migration
    php bin/console doctrine:migrations:migrate
    php vendor/bin/phpunit -c phpunit.dist.xml

Les nouvelles colonnes sont NULLABLE : aucun impact sur les dons existants,
et les tests webhook existants doivent rester verts sans modification
(les méthodes ajoutées sont appelées de façon défensive).

## Déploiement prod (CT 202)

    git pull
    composer install --no-dev --optimize-autoloader
    php bin/console doctrine:migrations:migrate --env=prod
    php bin/console cache:clear --env=prod

## Rattrapage du don existant (CT 203, don id 10 : 1,00 €, frais 0,27 €, net 0,73 €)

    su - postgres -c "psql geomonkey -c \"UPDATE donations SET payment_status = 'paid', fee_amount = 27, net_amount = 73 WHERE id = 10;\""
